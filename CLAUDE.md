# CLAUDE.md — правила работы над RemixClient

Этот файл читают все агенты, которые работают в репозитории. Нарушение любого пункта —
повод откатить правку, поэтому сначала прочитай целиком.

## Что это за проект

RemixClient — независимый офлайн-лаунчер Minecraft (форк OneLauncher, GPL-3.0) и свой
Fabric-мод-компаньон. Репозиторий плоский: Rust-воркспейс, `.github` и мод лежат в корне.

```
Cargo.toml            workspace
packages/             oneclient_app (UI), oneclient_core, oneclient_auth, ...
companion/            Fabric-мод (Java 25, Minecraft 26.3)
.github/workflows/    ci.yml, release.yml, cleanup-releases.yml
docs/                 terms.md, privacy.md, guide-ru.md
tools/                skinpack CLI, telegram-post.ps1
servers.json          каталог серверов, который читает лаунчер
```

## Сборка и проверка

```powershell
C:\Users\user\msvc.cmd cargo check -p oneclient_app
C:\Users\user\msvc.cmd cargo test -p oneclient_core --lib -j 1
C:\Users\user\msvc.cmd cargo test -p oneclient_app --lib i18n
cd companion; ./gradlew.bat build
```

- Перед отчётом об успехе **всегда** запускай проверку из списка выше. Не пиши «собралось»,
  если не видел `Finished` / `BUILD SUCCESSFUL`.
- Если проверка падает — это твоя задача, а не «известная проблема».
- `cargo fmt --all` обязателен: CI падает на форматировании.

## Границы

- Работай **только** в тех файлах, которые названы в задаче. Не «заодно» рефакторишь.
- Не коммить и не пушить, если это не разрешено отдельно. Ветки и историю не переписывай.
- Не меняй `Cargo.toml` версии, `servers.json`, ключи подписи и `.github/workflows` без явной задачи.
- Чужие строки, комментарии и лицензионные заголовки не удаляй.

## Жёсткие запреты

1. **Платные модели для суб-агентов.** Только бесплатные/flash: `qwen-3.8-flash`,
   `deepseek-v4.1-flash`, `glm-5.3-flash`, `mimo-2.6-flash`, `minimax-m3.1-flash`,
   `solar-mini-4`. Никаких Claude/Opus/GPT/max/pro для дочерних задач.
2. **Ссылки на Polyfrost.** Ни `discord.gg/polyfrost`, ни `polyfrost.org/legal`, ни их
   метаданные. Наши: `https://t.me/remixclient_ru`, `github.com/linkure8888-lang/OneLauncher`.
3. **Телеметрия.** Никакой аналитики, Sentry без `REMIXCLIENT_SENTRY_DSN`, никаких запросов
   «домой». Офлайн-аккаунт не должен трогать сеть вообще.
4. **Платный доступ к игре.** Проект бесплатный: донат — только косметика и удобства.
5. **Деструктивные операции с git** (`push --force`, `reset --hard`, удаление веток/тегов)
   без прямого разрешения.

## Правила кода

- Текст интерфейса — только через `t("oneclient....")`; новые ключи добавлять **и** в
  `lang/en_us.json`, **и** в `lang/ru_RU.json`, иначе тест `i18n` падает.
- Комментарии в коде — по-английски, объясняют «почему», а не «что».
- Не оставлять мёртвый код, неиспользуемые константы и `let mut`, который не мутируется.
- Ошибки не глотать: `unwrap_or_default()` на чтении пользовательских файлов запрещён —
  он превращает ошибку в пустой файл и теряет данные.
- Любая работа с путями от пользователя — с проверкой на `..` и абсолютные пути.

## Что уже сделано (не переделывать без причины)

- Офлайн-аккаунты (`MD5("OfflinePlayer:<ник>")`, `--userType legacy`, `--accessToken 0`).
- Portable-режим, бэкапы миров, офлайн-скины и библиотека скинов с превью.
- Каталог серверов с TCP-пингом, каталог читается из `servers.json`.
- Пресет по железу: FPS = герцовка монитора, рендер не ниже 80%, память ≤ половины ОЗУ.
- Свои Terms/Privacy, RU-локаль, иконка, Telegram вместо Discord, подписанные релизы.
- Мод: HUD (броня/оружие/тотемы) и панель настроек на **Right Alt**.
