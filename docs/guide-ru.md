# RemixClient — руководство пользователя

> Офлайн-первый Minecraft-лаунчер. Без лицензии, без аккаунта Microsoft — ввёл ник и играешь.

---

## Установка

### Windows (.msi)

Скачайте последний `RemixClient_<версия>_x64_en-US.msi` со страницы
[Releases](https://github.com/linkure8888-lang/OneLauncher/releases/latest)
и запустите. Лаунчер появится в меню «Пуск» и удаляется через
«Приложения и возможности».

### macOS (.dmg)

Скачайте `.dmg` из Releases, откройте образ и перетащите RemixClient
в папку «Программы». При первом запуске macOS может попросить разрешение
в «Настройках безопасности».

### Linux (.deb)

Скачайте `.deb` из Releases и установите:

```bash
sudo dpkg -i remixclient_<версия>_amd64.deb
sudo apt-get install -f   # если нужны зависимости
```

## Первый запуск и онбординг

При первом запуске RemixClient покажет приветственный экран:

1. Примите условия использования и политику конфиденциальности.
2. Выберите язык (русский доступен из коробки).
3. Создайте офлайн-аккаунт или войдите через Microsoft.
4. Лаунчер автоматически найдёт или установит нужную версию Java.

Если у вас уже стоял OneClient, данные будут перенесены автоматически.

---

## Офлайн-аккаунт

Введите любой ник — RemixClient создаст локальный UUID по формуле
`MD5("OfflinePlayer:<ник>")` и запустит игру с `--userType legacy`.
Никаких запросов к Microsoft или Mojang не делается.

**Ограничения:**
- Онлайн-серверы (с `online-mode=true`) вас не пустят — для них нужен
  лицензионный аккаунт Microsoft.
- Мультиплеер работает на серверах с `online-mode=false` и по LAN.
- Социальные функции (Poly+, друзья, приглашения) недоступны без Microsoft.

---

## Вход через Microsoft (опционально)

Авторизация через Microsoft необязательна. Она нужна, только если вы хотите
играть на онлайн-серверах или использовать соцфункции.
Перейдите в **Аккаунты → Добавить → Microsoft** и следуйте инструкциям.

---

## Portable-режим

Запустите лаунчер с флагом `--portable` (или `-p`), и все данные будут
храниться рядом с `.exe` в папке `RemixClient-data`, а не в `%APPDATA%`.
Удобно для USB-флешки или переносной установки.

Также можно создать файл `portable.txt` рядом с исполняемым файлом —
лаунчер автоматически перейдёт в portable-режим.

## Бэкапы миров и восстановление

RemixClient автоматически создаёт резервную копию изменённых миров
**перед каждым запуском** игры. Хранится до 5 последних копий.

Чтобы восстановить мир:
1. Откройте нужную версию → вкладка **Миры**.
2. Правый клик по миру → **Бэкапы…**
3. Выберите резервную копию и нажмите **Восстановить**.

При восстановлении текущий мир сначала сохраняется как страховочная копия,
так что ничего не потеряется.

Бэкапы хранятся в `<папка версии>/backups/worlds/<мир>/`.

---

## Офлайн-скины и плащи

RemixClient умеет загружать скины и плащи из локальных файлов — без
обращения к серверам Mojang. Скин будет виден в игре благодаря локальному
HTTP-серверу на loopback-адресе.

Настроить скин можно в **Аккаунты → Выбрать аккаунт → Скин/плащ**.

Файлы скинов хранятся в `<папка данных>/skins/<UUID аккаунта>/`.

---

## Где лежат данные

| Сборка | Папка |
|---|---|
| Release | `%APPDATA%\Remix\RemixClient` |
| Debug | `%APPDATA%\Remix\RemixClient-dev` |
| Portable | `<папка .exe>\RemixClient-data` |

Логи находятся в подпапке `logs/` внутри папки данных лаунчера.

---

## Как приложить лог при проблеме

1. Откройте **Настройки → Лаунчер → Открыть папку лаунчера**.
2. Зайдите в папку `logs/`.
3. Скопируйте последний `.log`-файл и приложите его к сообщению.

Также можно воспользоваться **Настройки → Помощь → Отправить отчёт** — лаунчер
подготовит лог и откроет страницу создания issue.
