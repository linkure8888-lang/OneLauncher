# telegram-post.ps1 — публикация в Telegram

## Быстрый старт

1. Откройте Telegram, найдите **@BotFather**, отправьте `/newbot`, следуйте инструкциям.
   BotFather выдаст токен вида `123456:ABC-DEF…`.

2. Добавьте бота **админом** в канал `@remixclient_ru` (или ваш канал).
   Без прав админа бот не сможет публиковать.

3. Сохраните токен в `.env` **в корне репозитория** (файл в `.gitignore`, в git не попадёт):
   ```
   tg-token=123456:ABC-DEF…
   ```
   Подойдёт любое из имён: `tg-token`, `TG_TOKEN`, `REMIX_TG_TOKEN`. Скрипт читает `.env`
   первым, потом переменную окружения `REMIX_TG_TOKEN`, потом `%USERPROFILE%\.remix\tg-token.txt`.

   ⚠️ Никогда не коммитьте `.env` и не вставляйте токен в чат. Если токен утёк —
   `@BotFather` → `/revoke` (старый сразу перестанет работать).

4. Проверьте через dry run (ничего не отправляет):
   ```powershell
   .\tools\telegram-post.ps1 -Text "Привет, мир!" -DryRun
   ```

5. Отправьте в канал:
   ```powershell
   .\tools\telegram-post.ps1 -Text "<b>RemixClient 0.2</b> — новая версия!"
   .\tools\telegram-post.ps1 -File .\changelog.md -Silent
   ```

## Защита бота (сделать один раз)

- `@BotFather` → `/setjoingroups` → **Disable**: бота нельзя будет добавить в любой чужой
  чат, только туда, куда позовёте сами (канал).
- `@BotFather` → `/setprivacy` → **Enable**: в группах бот видит только команды, не переписку.
- Права в канале: только **Post messages**, **Edit messages**, **Delete messages**,
  **Pin messages**. Админом с правом добавлять других админов — никогда.
- Скрипт постит **только** в `@remixclient_ru` и отказывается писать в другие чаты без
  явного флага `-AllowAnyChat`. Это защита от случайного спама в группы.

## Параметры

| Параметр | Описание |
|---|---|
| `-Text "..."` | Текст сообщения (HTML-теги `<b>`, `<i>`, `<a>` поддерживаются) |
| `-File <путь>` | Альтернатива `-Text`: прочитать текст из `.md`/`.txt`-файла |
| `-ChatId` | ID канала; по умолчанию `@remixclient_ru` (или `REMIX_TG_CHAT`) |
| `-AllowAnyChat` | Разрешить отправку НЕ в канал (только для тестов) |
| `-Silent` | Отправить без звукового уведомления |
| `-DryRun` | Показать, что будет отправлено, без реальной отправки |
